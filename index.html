// 01 — About

Who is
cal.me_j? ;)

I’m Jesse Muuya, a full-stack developer who builds and runs multi-tenant platforms end to end: the React interface, the API, the database, the payment flow and the server it all runs on.

I work across the stack: React on the front, NestJS, Node/Express and TypeScript on the back, PostgreSQL, Supabase and MongoDB for data, deployed on AWS EC2 behind Nginx with Redis where needed. Python, WordPress and CodeIgniter when the job calls for them.

I care about the parts users never see: role-based access, signed webhooks, validated inputs and traceable approvals, and I’m deepening that into cloud and security engineering.
